# Round 20 — Windows checklist

The headless suite proves the logic on every push. These are the things only a real rig shows:
one line per item, what to do, and what you should see. Tick them on a Windows machine with the
full build (libVLC bundled), two displays, a phone or tablet on the same network, and Companion
2.7.0 if you drive the desk from a Stream Deck.

| # | Item | Do | Expect |
| --- | --- | --- | --- |
| 3 | The screens re-owned after a hang | With two displays and OUTPUTS ON, open Task Manager and **suspend** the Patterns process (Details → right-click → Suspend) so the windows keep their last picture and the desk stops answering; wait fifteen seconds; start Patterns again from the exe | The new desk comes up, the health line and Machine → STABILITY read *Took 2 screens (…) back from the last run (pid …, ended — it had stopped answering); the show is back on them*, the suspended process is gone from Task Manager, the outputs are open again on both displays showing what was on air, and OUTPUTS OFF now closes them — the picture is this desk's to stop |
| 3b | A second desk asked politely | With Patterns live on both displays, start a **second** Patterns from the same folder | The first desk's outputs close on their own within a second, its status line reads *Another Patterns (pid …) started and took the screens over — this desk's outputs are closed*, nothing is killed, and the second desk opens the outputs with the show back on them; only one set of windows is ever on the displays |
| 3c | The ordinary cases are untouched | Close Patterns cleanly and start it again; then pull the power (or hard-reset) mid-show and start it again; then untick Machine → *Take the screens back from a run that is still playing*, suspend the process as in row 3 and start again | The clean restart says nothing about screens and opens none by itself; the power-cut restart puts the show back the way it always did (the dead process's record is swept up silently — nothing was still playing); with the tick off the new start leaves the old windows alone and the health line says so, naming the pid to close by hand |
| 2 | The drop is told from the nearest anchor | BUILD → Overlays with the clock on: note its Position (Center) and Nudge X / Y; drag the clock on the PREVIEW pane into the bottom-right corner and let go; look at Position and the Nudge sliders; now drag the Size slider up and down; then join the two displays into one wide canvas on SETUP → Screens and look at the corner | The clock does not move a pixel when you let go, but Position reads **Bottom right** and the Nudge sliders come back to near zero; growing and shrinking the clock keeps it in the corner instead of sliding out of it; on the joined wide canvas it is still in the bottom-right corner, not stranded in the middle-right |
| 2b | Place X / Y in pixels | On the same page, read the **Place X / Y (px)** fields and the line under them; drag the clock and watch them; type an exact pair (say 96 and 54) and press Tab; do the same on BUILD → Countdown and on BUILD → Branding for the badge; turn an overlay off and look at its fields | The fields read the box's top-left on the canvas the PREVIEW pane is showing and the line names the box's size and the canvas's; they follow a drag within a second; typing puts the box's top-left on exactly those pixels and the Nudge sliders move to match; with the overlay off the fields grey out and the line reads *Not on the picture yet* |
| 1 | One key for the countdown | On the phone remote's OVERLAYS tab press the new **COUNTDOWN** key twice; on a Stream Deck drag the *COUNTDOWN — what is left* preset from Companion 2.7.0 and press it twice; from a TCP or OSC test tool send a bare `COUNTDOWN`, then `/patterns/countdown` with no argument | Each press turns the countdown on as the Countdown page has it set up (to the time of day it points at, else its duration counting from now) and the next press takes it off; the phone key lights and reads *COUNTDOWN — ON (stop)* while it is on; the Stream Deck key is green while it runs and red when it is over, and stops it on the second press; the wire and OSC answer `OK` and the screens follow |
| 1b | The toggle in a cue and on the sheet | PLAN → Cues: add an action to a cue and pick **Countdown on / off**; export the stack to a sheet, re-import it | The picker offers it beside Start / Stop countdown, the cue row summarises it as *Countdown on / off*, firing the cue flips the countdown on air, and the exported sheet re-imports as the same action |
