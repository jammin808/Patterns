# Round 16 — Windows checklist

The headless suite proves the logic on every push. These are the things only a real rig shows:
one line per item, what to do, and what you should see. Tick them on a Windows machine with the
full build (libVLC bundled), two displays and an audio interface; row 1 also wants a Stream Deck
with Companion. The round is a refactor of the action path — one vocabulary, one executor — so
the rows are about the same verbs reaching the screens from every source, and about an older
show file loading as it did.

| 2 | The wire speaks the vocabulary | With Companion connected and the caller's stack holding three cues, and *Allow remotes to arm* off on SETUP → Remote: from a telnet line send `CUE ARM ON`, then tick *Allow remotes to arm* and send it again, `CUE STANDBY NEXT`, `CUE STANDBY 2`, `CUE STANDBY Walk-in` (a cue's name), `CUE HOLD ON`, `CUE GO`, `CUE HOLD OFF`, `CUE GO`, `LOOK #2`, `LOOK #9`, `SCREEN 2 LOOK Sponsor Logo`, `FADE 1.5 SCREEN 2`, `STOPALL`, `PING`, `HELLO FOH deck`, `FROBNICATE`; on the Run surface press ARM, HOLD, ▲ and ▼ and the Up / Down keys; press a Companion Cue-bank key and a Look-bank key; open the journal | The first `CUE ARM ON` answers `ERR remotes may not arm — allow it on the Remote page` and the stack stays disarmed; the second answers `OK` and the Run strip reads ARMED; each STANDBY moves the standby cue on the strip and answers `OK {"standby":…}` with nothing on air; with HOLD on, `CUE GO` answers `ERR` with the hold's sentence, and after `CUE HOLD OFF` it answers `OK {"outcome":…,"last":…,"standby":…}` and the cue fires; `LOOK #2` puts the second look on air and `LOOK #9` answers `ERR no look #9 — the show has 3`; the screen's own look, the one-screen fade and STOPALL land as before; `PING` answers `OK PONG`, `HELLO` names the line, `FROBNICATE` answers `ERR unknown command 'FROBNICATE'`; ARM, HOLD, ▲ ▼ and the keys do the same as the wire did; the Companion keys fire and light as before; the journal reads one row per GO, hold and arm with its source (desk, keyboard, tcp FOH deck, companion) and no row for a standby move |
