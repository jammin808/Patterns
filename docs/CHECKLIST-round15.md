# Round 15 — Windows checklist

The headless suite proves the logic on every push. These are the things only a real rig shows:
one line per item, what to do, and what you should see. Tick them on a Windows machine with the
full build (libVLC bundled), two displays and an audio interface. Row 1 is the report's crash
between menus: do it on the machine it happened on, and after any restart read the health line
before touching anything — the sentence it shows is the evidence.

| 2 | The editing target never blank | Two displays: OWN on the second screen's tile, then on the Pattern page read EDITING TARGET; LOCK and unlock the first screen's tile; on the Screens page type a label for the second screen; OWN on the first tile too, then pick the second screen back in EDITING TARGET; OWN off on the second; OWN off on the first; load a saved show with own patterns; plug a display out and in | EDITING TARGET reads the second screen from the moment OWN goes on and keeps reading it through the lock, the unlock and the label (the label appears in the picker and in the EDITING banner at once) — never a blank box; the second OWN moves the editors to the first screen and picking the second back holds; OWN off puts the picker on Program (still shown while another screen has its own pattern), and with every own pattern gone the picker hides and the banner reads EDITING: PROGRAM; a loaded show and a display change never leave the box blank |
