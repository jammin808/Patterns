# Round 18 — Windows checklist

The headless suite proves the logic on every push. These are the things only a real rig shows:
one line per item, what to do, and what you should see. Tick them on a Windows machine with the
full build (libVLC bundled), two displays and an audio interface. The round came from four
questions — a Fractals page like the Particles page, whether the particles need the fractals'
treatments, a faster start and restart, and what .NET 10 buys — so the rows are the studio, the
sim under load, the stopwatch at the start, and the runtime.
